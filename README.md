This project addresses the challenge of predicting the properties of complex fuel blends containing both sustainable and conventional components. It uses advanced data preprocessing, feature engineering, and machine learning techniques to build robust, high-accuracy models that estimate critical fuel characteristics crucial for sustainable aviation fuels and energy transition.

Key Features:
Data preprocessing with imputation and scaling for handling high-dimensional, incomplete industrial datasets.
Feature selection tailored to each fuel property using CatBoost’s importance scores to optimize prediction efficiency.
Ensemble modeling combining CatBoost and Artificial Neural Networks to achieve R² > 0.99 and MAPE < 0.13 across multiple blend properties.
Automated model evaluation pipeline including error analysis and visualization for reliable, actionable predictions.
